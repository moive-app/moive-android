- **조건 입력**: 참여자마다 가능한 일정, 출발지, 이동 가능 시간, 취향(놀거리 · 먹을거리)을 직접 입력해요
- **지역 · 장소 추천**: 추천 지역 3곳과 지역별 장소 3곳을 평균 · 최장 이동시간, 취향 일치율과 함께 보여줘요
- **날짜 자동 확정 · 장소 투표**: 각자 되는 날짜만 고르면 가장 많이 겹치는 날로 MOIVE가 정해줘요. 장소는 투표로 고르고, 전원이 투표하면 모임이 자동으로 확정돼요
- **멤버별 이동시간**: 확정된 모임에서 누가 얼마나 걸리는지, 환승은 몇 번인지 한눈에 확인해요
- **홈 · 알림**: 다가오는 모임과 D-day를 홈에서 보고, 추천 완료나 투표 마감은 알림으로 받아요
- **초대 링크**: 링크로 바로 모임방에 들어올 수 있어요
